I built an AI-powered Interview Scheduling Automation system that simplifies coordination between candidates and interviewers.

The system takes candidate availability and multiple interviewer schedules as input. I designed a logic that parses time ranges, converts them into comparable formats, and calculates overlapping time slots.

Based on overlap, the system ranks and suggests the top 3 interview slots by prioritizing maximum participant availability and optimal timing. It also highlights conflicts where certain interviewers are unavailable and provides reasoning for each recommendation.

I focused on building a practical, usable solution with a clean interface that mimics a real-world scheduling assistant. The system reduces manual back-and-forth and improves efficiency in hiring workflows.

This approach demonstrates structured thinking, automation capability, and real-world applicability.
